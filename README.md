双击 `start.bat`（或中文入口 `更新并查看公告.bat`），程序会监听 `http://0.0.0.0:9092/`，并用浏览器打开本机地址 `http://127.0.0.1:9092/`。程序每 3 分钟更新全部平台一次，关闭命令窗口即可停止。HTML 每页最多显示 30 条公告。

## 添加其他公交来源

在 `sources` 目录增加一个来源模块。模块需要提供 `SOURCE` 字典，其中包含：

- `id`：英文唯一标识，用作输出文件名。
- `name`：公交名称。
- `fetch`：无参数函数，返回公告字典列表。

公告字段统一为 `id`、`date`、`title`、`type`、`image`、`description`、`url`。最后在 `sources/__init__.py` 中导入并加入 `SOURCES` 即可。
